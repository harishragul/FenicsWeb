4. Convection-diffusion convergence — Galerkin vs. SUPG

Problem: −u″ + Pe·u′ = 0, u(0)=0, u(1)=1. Exact solution: u(x) = (ePe·x − 1) / (ePe − 1). min/max show the smallest and largest nodal values — the exact solution is bounded in [0,1], so values outside this range indicate spurious oscillations (occurs for standard Galerkin when the cell Peclet number Peh > 1).
